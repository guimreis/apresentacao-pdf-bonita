# Créditos das fotos

As três fotos desta pasta são do Unsplash (unsplash.com), sob a licença do Unsplash, que permite uso
gratuito, inclusive comercial. O código no nome do arquivo é o da foto no site:
`https://unsplash.com/photos/<código>`.

A fonte Schibsted Grotesk (pasta `fontes/`) é da Schibsted, sob a SIL Open Font License 1.1 (`fontes/OFL.txt`).
